Remarks

Every documented easing function has the signature math.ease_x(start, end, 0_to_1) and "Output goes from start to end via 0_to_1", so each curve below maps an interpolant in [0, 1] onto a weight that is 0 at t=0 and 1 at t=1. Interpolate(Func<double, double>, double, double, double) applies that weight to the start/end pair.
